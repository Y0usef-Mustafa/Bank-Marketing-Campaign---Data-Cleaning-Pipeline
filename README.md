# Bank Marketing Campaign - Data Cleaning Pipeline

## 📌 Project Overview
Personal loans are a lucrative revenue stream for banks. The typical interest rate of a two-year loan in the United Kingdom is around 10%. This might not sound like a lot, but in September 2022 alone, UK consumers borrowed around £1.5 billion, which would mean approximately £300 million in interest generated by banks over two years!

This project involves cleaning and reformatting data collected from a recent bank marketing campaign aimed at getting customers to take out personal loans. To prepare for future marketing initiatives, the raw data (`bank_marketing.csv`) has been cleaned, structured, and split into specific formats so it can be seamlessly imported into a **PostgreSQL** database for efficient storage and future analysis.

---

## 🏗️ Data Structure & Deliverables
The original dataset has been processed and split into three specific CSV files, each fulfilling precise schema and cleaning requirements:

### 1. `client.csv`
Contains demographic and financial information about the clients.

| column | data type | description | cleaning requirements |
|--------|-----------|-------------|-----------------------|
| `client_id` | `integer` | Client ID | N/A |
| `age` | `integer` | Client's age in years | N/A |
| `job` | `object` | Client's type of job | Change `"."` to `"_"` |
| `marital` | `object` | Client's marital status | N/A |
| `education` | `object` | Client's level of education | Change `"."` to `"_"` and `"unknown"` to `np.NaN` |
| `credit_default` | `bool` | Whether the client's credit is in default | Convert to `boolean` data type:<br> `1` if `"yes"`, otherwise `0` |
| `mortgage` | `bool` | Whether the client has an existing mortgage (housing loan) | Convert to boolean data type:<br> `1` if `"yes"`, otherwise `0` |

<br>

### 2. `campaign.csv`
Contains details about the bank's contact with clients and the campaign outcomes.

| column | data type | description | cleaning requirements |
|--------|-----------|-------------|-----------------------|
| `client_id` | `integer` | Client ID | N/A |
| `number_contacts` | `integer` | Number of contact attempts to the client in the current campaign | N/A |
| `contact_duration` | `integer` | Last contact duration in seconds | N/A |
| `previous_campaign_contacts` | `integer` | Number of contact attempts to the client in the previous campaign | N/A |
| `previous_outcome` | `bool` | Outcome of the previous campaign | Convert to boolean data type:<br> `1` if `"success"`, otherwise `0`. |
| `campaign_outcome` | `bool` | Outcome of the current campaign | Convert to boolean data type:<br> `1` if `"yes"`, otherwise `0`. |
| `last_contact_date` | `datetime` | Last date the client was contacted | Create from a combination of `day`, `month`, and a newly created `year` column (which should have a value of `2022`); <br> **Format =** `"YYYY-MM-DD"` |

<br>

### 3. `economics.csv`
Contains macroeconomic indicators recorded at the time of the campaign.

| column | data type | description | cleaning requirements |
|--------|-----------|-------------|-----------------------|
| `client_id` | `integer` | Client ID | N/A |
| `cons_price_idx` | `float` | Consumer price index (monthly indicator) | N/A |
| `euribor_three_months` | `float` | Euro Interbank Offered Rate (euribor) three-month rate (daily indicator) | N/A |

---

## 🛠️ Technologies Used
* **Python:** Core language for data manipulation.
* **Pandas:** Utilized for string manipulation, boolean mapping, missing value handling (`np.NaN`), and datetime engineering.
* **CSV:** Standardized export format for integration with relational databases (PostgreSQL).

---

## 🚀 Execution Steps
1. Ensure the raw `bank_marketing.csv` file is located in the root directory.
2. Run the Python data processing script.
3. The script will apply all cleaning requirements and automatically generate `client.csv`, `campaign.csv`, and `economics.csv`.
4. The generated files are formatted and ready for immediate database import.
